# Visión de producto

## Norte

OAW será la interfaz web oficial del ecosistema del Orquestador de Agentes: una consola segura para crear tareas, observar ejecuciones, aprobar acciones, consultar memoria y auditar decisiones.

## Principios

1. La seguridad precede a la comodidad.
2. Cada tarea tiene identidad, eventos y receipt.
3. El navegador nunca ejecuta agentes directamente.
4. La interfaz debe servir tanto a una persona como a una futura plataforma multiusuario.
5. Las atribuciones y licencias de proyectos inspiradores se mantienen visibles.
6. El roadmap es vivo y puede cambiar mientras se define el producto.

## Capacidades objetivo

- Sesiones y proyectos.
- Tareas con streaming y cancelación.
- Receipts y auditoría end-to-end.
- Aprobaciones y políticas de seguridad.
- Workspace y estado Git.
- Routing de agentes/modelos.
- Capacidades, cuotas y confiabilidad.
- Memoria, workflows y tareas programadas.
- Acceso seguro desde navegador y móvil.
