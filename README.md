# OAW — Orquestador de Agentes Web

OAW es una futura interfaz web AGPLv3 para orquestar, supervisar y auditar agentes, tareas, herramientas y workflows.

## Estado

Proyecto conceptual. El norte y el roadmap evolucionarán antes de iniciar la implementación funcional.

## Inspiraciones

OAW toma ideas y patrones de:

- `agent-orchestrator` de Terracenter.
- Orque.
- `hermes-webui` de Nesquena (MIT).
- Otras interfaces web y consolas de agentes, documentadas en `CREDITS.md`.

La inspiración conceptual no implica reutilización de código. Todo código externo reutilizado conservará sus avisos y licencia original.
