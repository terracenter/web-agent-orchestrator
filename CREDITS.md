# Inspiraciones y atribuciones

OAW reconoce las ideas, patrones y trabajo de los proyectos que lo inspiran:

- **agent-orchestrator** — base del motor de ejecución, delegación, políticas y receipts.
- **Orque** — inspiración para la coordinación y operación de agentes.
- **hermes-webui** — inspiración para sesiones web, streaming, workspace, aprobaciones, móvil y operación doméstica. Proyecto original: `https://github.com/nesquena/hermes-webui`, licencia MIT.

Esta lista se ampliará cuando se incorporen otras referencias. El código reutilizado conservará sus avisos de copyright y licencias originales.
